Ranked predictions
- Avoiding unchanged uniform uploads should reduce bufferSubData calls and JS
  time even with exactly the same meshes, layers, resolution and visual detail.
- If static layer submission still dominates, caching it should reduce draw
  calls and CPU time between scene/camera changes without losing interactions.
- If React/data projection dominates, separating unchanged projections from
  playback publication should remove periodic long tasks rather than GPU cost.

Implemented and measured
- Patched luma.gl/core 9.3.6's UniformBlock dirty flag at the changed-value seam.
  Source, ESM and CommonJS implementations are patched via pnpm; the lockfile
  records its hash, and both Docker builders copy patches before installing.
  An actual UniformStore regression verifies first upload, unchanged blocks,
  partial updates, and in-place typed-array edits.
- Cached Mercator's ground geography, footprints and route guides in a single
  screen-sized framebuffer, within the existing WebGL context. Camera, size,
  layer, visibility and loading changes invalidate it. Columns, markers, labels

  available to GPU picking. The cache is released on quality change/unmount.
  Full detail retains its ordinary MapLibre rendering. This uses Deck's exported
  experimental _LayersPass API, verified with the locked 9.3.11 version; retain
  the cache browser regression when upgrading Deck. At the tested 1630x777
  canvas the RGBA and depth/stencil attachments use approximately 10 MB total.
- Decoupled animation paints from quantized timeline frame notifications. One
  30 Hz paint gate now reads continuous playback time, including at half speed;
  React retains its bounded publication rate and paused/hidden maps stay idle.
- Removed the Connect to/retention instruction banner while retaining actual
  capture or connection warnings. Restored the normal demo map's timeline,
  keyboard controls, waveform and explicit Go live behavior. Expanding/collapsing
  retains replay. Removed the obsolete guard that ignored immediate pause clicks.

Follow-up: Active now and outage recovery, 2026-10-01
The production demo uses real capture. The user's phone generated real flows and
packet chunks; two dashboard clock bugs were exposed after another USB outage.
1. The backend advances manifest.startedAt with the retained history window.
   MapPage incorrectly reused that moving boundary as its playback frame origin.
   A paused clock advanced 20 seconds during a 13-second check against the real
   gateway. Eventually it displayed a future instant, making Active now empty.
   MapPage now pins the first frame origin for each session; only the visible
   retention boundary moves. Earlier fixture checks did not move startedAt as
   production does and therefore missed this regression.
2. An outage longer than the animation headroom emitted ended and changed live
   following to paused. The next reconnect could not resume automatically.
   Reaching this temporary bound now preserves live intent. An explicit user
   pause still sets paused, and recorded playback still stops normally.
