# Debug UI redesign validation

7 September 2026. Design reference: [Workspace study 03](../../../redesign-report.html). Delivery checklist: [implementation-plan.md](../../../implementation-plan.md). Reproduction commands and fixture controls are in the [debug workspace README](../../../debug-dashboard/README.md).

Screenshots, command logs and JSON results named below are generated local evidence and are not versioned. The browser scripts in `debug-dashboard/test-support` reproduce these artifacts.

## Scope and environment

Validated Sessions, Traffic and Lab against the local gateway fixture on `127.0.0.1:8095`, using Chromium and the Vite development server. Hardware: Apple M1 Max, arm64, 64 GiB RAM. The fixture supplies five sources (two active), source timestamps with millisecond precision, optional metadata, partial capture, SSE and authenticated simulated gate controls. Its public test credential cannot control a real gateway.

The configured physical gateway was unreachable during this work. No physical gate, interface, firewall, throughput or fail-open claim follows from these UI checks. Outstanding checks remain in the [original Proxy Lab plan](../../implementation-plans/proxy-lab-original.md), [Pi acceptance record](../proxy-lab-raspberry-pi.md) and [flow capture Pi record](../flow-activity-raspberry-pi.md).

## Large recording profile

Profile data (`performance.json`), 10,000-flow view (`traffic-10000.png`). Dataset: 10,000 flows, 8,000 DNS records and associated hostname/activity evidence over a 60-second recording; the fixture returns one-second activity buckets for requested flows. Vite development mode, including React development checks, was used. The fixture does not reproduce backend pagination or physical capture throughput, so these are local navigation measurements, not a production capacity promise.

| Measurement | Observed |
| --- | --- |
| Overview available after navigation | 3,015 ms |
| Five seek interactions | 1,123 / 28 / 85 / 13 / 18 ms |
| 120 playback frames: median / p95 | 16.7 / 33.4 ms |
| Largest frame gap | 1,933.2 ms |
| Rendered tracks / clips | 19 / 16 |
| DOM nodes / JavaScript heap | 1,852 / 182,288,106 bytes |
| Detail requests / largest request interval | 24 / 10 seconds |
| Maximum requested flows per detail request | 18 |
| Detail cache | 21,247,112 bytes; 13 pages; 0 pending, within 50,331,648-byte budget |

The profile exposed excessive marker rendering and repeated locale formatter allocation. Reusing formatters and unchanged track content, virtualizing the ledger, and moving the visible playback window in bounded steps brought normal frame times down. Cold detail projection still caused a one-second seek and an occasional roughly two-second frame gap in this development fixture. This remains a performance limitation for dense cold loads; it is recorded rather than hidden by a warm-only benchmark. Pointer movement is debounced before range loading, selected evidence has its own request owner, and obsolete requests are cancelled. The navigator does not request an entire recording at fine resolution.


## Sustained stream and lifecycle

Lifecycle results (`lifecycle.json`): 15 checks passed. Over 40 seconds at 20 incoming events/second, the live store grew from 20 to 600 retained events spanning 29,242 ms. The DOM had 741 nodes with 15 visible tokens; sampled JavaScript heap was 130,604,872 bytes (initial sample 114,431,680). This short bounded-retention check does not establish a multi-hour memory soak result.

Three repeated Sessions → Traffic → Lab cycles each had one trace subscription. Leaving Lab closed the stream, cleared its session/events/token, and left the shared cursor unchanged during a 500 ms observation, demonstrating that outgoing playback stopped. Stream gaps were visible separately from capture/audit quality, and reduced-motion node selection remained usable. Ending an active fixture source replaced Go live with a fixed recording End; deleting a selected source produced explicit missing-source states.

The production map (`production-dashboard-map.png`) opened `recorded-session` and loaded its 48 flows through the shared runtime. After playback advanced, the rendered map showed all 48 flows and destinations. Debug workspace styles were absent. No uncaught errors occurred in this run. Route checks also exposed and fixed a startup race: inspection controls now wait for bootstrap, and saved-cursor initialization verifies the source ID before applying it.
